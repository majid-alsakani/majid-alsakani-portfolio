Mizan مختبر محلي لفحص CSV وعقد البيانات. يجعل افتراضات schema والقيم الناقصة والتكرار وإشارات الخصوصية ظاهرة قبل دخول البيانات في تحليل أو workflow للذكاء الاصطناعي.

المشكلة والفرضية

قد يبدو الملف صالحًا بينما يحتوي فراغات أو صفوفًا مكررة أو تنسيقات غير متسقة أو حقولًا شخصية تحتاج ضوابط. لذلك صممت Mizan لتجعل قرار «مرر، راجع، أو أوقف» قابلًا للتفسير.

المستخدم الأساسي

محللو البيانات ومهندسو الذكاء الاصطناعي والفرق الصغيرة التي تحتاج preflight قبل بناء النظام الأكبر.

القرار التصميمي

العقد يوضح الافتراضات؛ لا يخفي عدم اليقين وراء رقم واحد.

يفصل التصميم بين parser وprofile وقواعد الجودة وإشارات الخصوصية وقرار العقد، حتى يمكن تغيير قاعدة دون تحويل الواجهة إلى صندوق أسود.

نتيجة الاختبار وحدودها

تحتوي العينة الافتراضية فراغًا وتكرارًا وبريدًا غير صالح وتاريخًا غير متسق. أنتج الاختبار المحلي **3 صفوف و5 أعمدة و5 نتائج و3 تحذيرات** وانتقل العنوان إلى `Review before modeling`. هذه ملاحظة fixture وليست نتيجة تجارية.

الحد: Mizan ليس منصة observability ولا يضمن أن البيانات مناسبة لنموذج معين.

الخطوة التالية

إضافة محرر عقد صريح، lineage، مقارنة batches، drift، مخرجات CI، وموصلات آمنة بعد تعريف الملكية والخصوصية والاحتفاظ بالبيانات.
