Designing a Bilingual Developer Roadmap (AR/EN)

By Majid Al-Sakani (ماجد السكني) · Updated 2026-08-03

Arabic-speaking beginners rarely lack motivation — they lack a trustworthy order of study. So I built an interactive roadmap that works fully in Arabic (RTL) and English, with eight paths from Frontend to AI and a dedicated professional engineering track.

Design principles

  • Order over volume: each node has prerequisites, so learners never jump blindly.
  • State belongs to the learner: Done / Learning / Skip is stored locally, no account required.
  • True bilingualism: not a translated layer — layout, direction and typography adapt.
  • Curated, free resources: official docs first, then high-quality Arabic video.

The professional track

Beyond syntax, the professional path covers engineering mindset, craft, reliability, architecture, security, DevOps, AI-augmented development and career growth — the topics that separate a coder from an engineer.
