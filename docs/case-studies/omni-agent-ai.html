Omni Agent AI — Case Study

By Majid Al-Sakani (ماجد السكني) · Full Stack Developer, Yemen · Updated 2026-08-03

PythonFastAPISSEDockerLLMpytest

The Problem

Most agent demos are prompt wrappers: no real tool execution, no observability, and no way to see why the model chose an action.

The Solution

A real engine — planner, executor, critic and memory — with a unified tool registry (web search, calculator, SQL, email) and server-sent events that stream every reasoning step live.

Results

DimensionOutcome
TransparencyEvery step is streamed and traceable in real time
ExtensibilityTools share one interface, so adding a capability is a single registration
QualityA critic loop re-plans when a step fails validation
ReproducibilityDocker, CI with ruff and pytest, documented architecture diagrams

My Role

I designed the architecture, implemented the backend and frontend, set up CI/CD and Docker delivery, and own the ongoing roadmap of the product.
