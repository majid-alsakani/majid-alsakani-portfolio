Use it well

Clean the title.
Then name the route.

The tool removes tatweel, repeated spaces and invisible direction marks. You can choose to remove diacritics or normalize selected Arabic letters, but the default preserves the text as closely as possible.

It creates a readable Arabic slug and a copyable URL-encoded value. The optional Latin conversion is conventional transliteration, not translation or a promise of better search ranking.

Is my text sent anywhere?

No. Processing happens in this browser and the tool does not make a network request with your text or slug.

Should I remove diacritics?

Not necessarily. Choose it only when you need a more uniform form for a system that does not handle diacritics well.

Can an Arabic slug be used in a URL?

Yes. The tool provides a URL-encoded form ready to copy. Use a consistent routing policy and do not change published URLs without appropriate redirects.
