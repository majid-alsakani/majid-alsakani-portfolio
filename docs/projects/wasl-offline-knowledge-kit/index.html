02 / Local-first model

Design for the missing signal.

Offline is not an error state in Wasl. It is a deliberate operating mode with clear limits.

03 / Project boundary

Useful does not need to be online.

Wasl is a dependency-free PWA showcase by Majid Al-Sakani — ماجد السكني. The MVP has no accounts, sync, or sensitive content. Production adoption would add signed packs, conflict-aware sync, encryption, and content governance.
