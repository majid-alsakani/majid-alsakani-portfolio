ثم أطلق.

الصق كائن JSON أو مصفوفته لتنسيقهما بمسافات مقروءة، أو صغّر حمولة صالحة للنقل. إذا كانت البيانات غير صالحة، تعرض النتيجة خطأ المحلل في المتصفح كي تصحح الصياغة قبل استدعاء API أو تعديل إعدادات.

تعمل هذه الأداة محلياً؛ وهي مناسبة لفحص حمولات API وبيانات الإعداد دون تنفيذ طلب شبكة من الصفحة.

هل تُرسل JSON إلى أي مكان؟

لا. يستخدم التنسيق والتحقق محلل JSON الأصلي في المتصفح، ولا تُرسل الأداة المدخلات.

هل يمكنها إصلاح JSON غير الصالحة؟

لا. تعرض خطأ الصياغة وتنسق JSON الصالحة فقط، كي لا تعدل حمولة تحتاج إلى فحصها بصمت.

ماذا يفعل التصغير؟

يزيل المسافات والسطور غير الضرورية من JSON الصالحة مع الحفاظ على القيم والبنية.
