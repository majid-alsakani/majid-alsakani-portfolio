Why teams keep it

Regression is a dataset

Reliable agents need cases that can be replayed after a prompt, tool, or policy change.

Tool calls are evidence

A final answer can look good while the path violates a tool or approval policy.

Compare before optimizing

Step count and duration help a team discuss tradeoffs without trusting a single score.

Architecture

TraceBench is a bounded local pipeline: JSONL parser, normalized events, outcome checks, tool policy, and a regression report.
