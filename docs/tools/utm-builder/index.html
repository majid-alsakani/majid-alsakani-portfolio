Growth utility / 04

Campaign links.
Without the drift.

BROWSER-LOCALThe URL is built in this browser. No campaign data is submitted to a server.
Your UTM URL will appear here.

Use it well

Name it once.
Measure it cleanly.

Enter the page you are linking to, a source and a medium. Add a campaign name so the finished URL has a clear purpose when you review analytics later. Term and content are optional labels for finer distinctions, such as a keyword or a particular button.

The builder preserves any existing parameters on the page URL and writes only the UTM values you provide. Use a consistent spelling convention in your team so similar campaigns do not become separate reporting labels.

Which fields are required?

The landing page URL and campaign source are required. Medium and campaign are highly recommended because they make traffic easier to interpret.

Will it remove existing query parameters?

No. Existing parameters remain in the URL. The builder adds or updates the UTM fields you supply.

Does the tool track clicks?

No. It only prepares a URL. Your analytics system records any campaign visit after you publish the link.
