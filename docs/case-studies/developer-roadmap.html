Developer Roadmap — Case Study

By Majid Al-Sakani (ماجد السكني) · Full Stack Developer, Yemen · Updated 2026-08-03

JavaScriptJSONGitHub PagesSEORTL

The Problem

Arabic learners follow scattered advice with no dependency order, and existing roadmaps are English-only with no progress state.

The Solution

An interactive roadmap engine: node-based maps for 8 tracks, a resource drawer per topic, local progress state, dark/light themes and full RTL.

Results

DimensionOutcome
Coverage8 tracks including a professional software engineering path
OwnershipProgress saved per learner without requiring an account
ReachFully bilingual AR/EN interface
DiscoverabilityStructured data and sitemaps for search indexing

My Role

I designed the architecture, implemented the backend and frontend, set up CI/CD and Docker delivery, and own the ongoing roadmap of the product.
