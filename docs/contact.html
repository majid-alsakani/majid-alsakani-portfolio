A clear next step
starts with an honest signal.

Bring the early idea, the awkward constraint, or the system that refuses to stay simple. This short path turns it into a first conversation that has somewhere useful to go.

THE WORKING METHODIdea → constraint → system → next decision

There is no need for a complete specification. Start where the work is most uncertain.

What wants to
become real?

Choose the closest starting point. It simply gives the first conversation a useful frame.

Where does the
work get hard?

The constraint is usually more useful than a feature list. Describe the point of friction, the context, or the decision that cannot stay vague.

What should the
system make possible?

A first outcome is enough. It can be a better decision, a faster path, a useful interface or a product that is safe to grow.
