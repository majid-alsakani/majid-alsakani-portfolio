JSON, made
readable.

BROWSER-LOCALYour JSON is processed in this browser. It is not sent to a server.
Your formatted JSON will appear here.

Use it well

Validate first.
Then ship.

Paste a JSON object or array to format it with readable indentation, or minify a valid payload for compact transport. When the data is invalid, the result identifies the browser parser error so you can correct the syntax before an API call or configuration change.

This utility is intentionally local: it is appropriate for debugging payloads and configuration data without making a network request from this page.

Does this send JSON anywhere?

No. Formatting and validation use the browser’s native JSON parser. The input is not submitted by this tool.

Can it repair invalid JSON?

No. It reports the syntax error and formats only valid JSON. This avoids silently changing a payload you may need to inspect.

What does minify do?

It removes indentation and unnecessary whitespace from valid JSON while preserving its values and structure.
