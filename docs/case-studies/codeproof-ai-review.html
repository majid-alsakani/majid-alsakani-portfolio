Case studies/03 · CodeProof
AI code review / 2026

Evidence over confidence.

CodeProof turns AI-generated code into a reviewable artifact. It points to obvious risk patterns, explains the rule, and keeps the final approval with a human reviewer.

Open live demo ↗View repository ↗

The problem

AI coding assistants can accelerate a first draft, but the draft still crosses security, correctness, and maintenance boundaries. A reviewer needs more than a green light: they need to know which line triggered a signal, why it matters, and what is still unverified.

Primary user

Developers, platform teams, and educators who want a review-first workflow around AI-assisted coding.

Product thesis

A finding is evidence for a decision, not a verdict. Human review and real tests remain part of the product.

What I built

CapabilityImplementationEngineering intent
Text boundaryLine tokenizer and local rulesNever execute arbitrary code in the public demo.
Risk rulesSecrets, eval, query concatenation, network boundariesStart with a small rule catalog that can be explained.
Evidence ledgerSeverity, line, explanation, suggested fixMake review traceable and reproducible.
Human gateExplicit “review required” statusPrevent the UI from implying automated approval.

Architecture

The system is deliberately arranged as input, line tokenizer, local risk rules, evidence ledger, finding, and human review. No execution engine is present in the MVP.

Evidence from the demo

The default fixture intentionally includes a credential-like string, a concatenated query, and `eval`. Local testing produced **three line-linked findings**, including two high-risk signals and one warning on lines 2, 3, and 4. This is a fixture result, not a security certification.

Decision: display the rule and line before any confidence language. Reviewers should see uncertainty, not be nudged into blind approval.

What I would build next

  • Replace regex rules with language-aware parsers and tested AST findings.
  • Add dependency and secret intelligence with safe, auditable data boundaries.
  • Export SARIF and integrate with CI policy without turning warnings into false certainty.
  • Add sandboxed test execution only as a separate, explicitly governed capability.

Boundary: CodeProof is a review workflow showcase. It is not a SAST replacement and cannot prove that code is secure.
