Agent evaluation / 2026

Reliability needs a replay loop.

TraceBench is a local-first evaluation workbench for AI agent traces. It makes outcome, step count, duration, and tool-policy behavior comparable before a team optimizes prompts or ships a new agent path.

Open live demo ↗View repository ↗

Problem and audience

A final answer can look correct while the agent took an unsafe or expensive route. The durable job is to keep regression cases, tool policies, and trace evidence replayable. TraceBench is for AI engineers, platform teams, and developers building tool-using workflows.

Durable job

Replay a case after a prompt, tool, model, or policy change and see what moved.

Design decision

Tool calls are first-class evidence; a final answer alone is not a reliability test.

Engineering decisions

DecisionChoiceReason
InputJSONL event tracePortable, inspectable, and easy to fixture.
ChecksOutcome, steps, duration, allowlistSmall deterministic checks make the result explainable.
OutputEvaluation evidenceSupports a future regression dataset and CI gate.

Architecture and media

The pipeline parses and normalizes events, applies independent checks, and produces a replay decision. It does not call a model in the public showcase.

Verified fixture behavior

The failing fixture produced three events and two tool calls in 960 ms. It showed one blocking policy signal for `shell_exec` and one latency warning, then returned `Review required`. These are fixture observations, not production reliability metrics.

Boundary: TraceBench is not a tracing backend, model judge, cost platform, or reliability guarantee.
