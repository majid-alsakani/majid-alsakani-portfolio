Auth utility / 02

Read the token.
Question the trust.

BROWSER-LOCALYour token is decoded in this browser. Decoding is not signature verification and does not make a token trustworthy.
The header and payload will appear here.

Use it safely

Read claims.
Verify elsewhere.

A JWT contains base64url-encoded header and payload data. This page makes those parts readable and translates an exp claim when present. It does not prove that the token was signed by a trusted issuer, has not been revoked, or should be accepted by an application.

Use this tool for inspection while debugging a login flow or API integration. Signature, audience, issuer and revocation checks belong in the service that accepts the token.

Does decoding validate a JWT?

No. The tool only reads the encoded header and payload. Never grant access merely because a token decodes successfully.

Is the token sent to a server?

No. Decoding runs in the current browser. This page does not submit the token.

What does exp mean?

When present, it is a Unix timestamp indicating an expiry time. It is still only a claim until a trusted server verifies the token signature and other requirements.
